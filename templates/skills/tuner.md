# Skills Tuner

The skills tuner companion skill. Use this skill to interact with the skills-tuner system.

## Modes

- `/tuner run` — run one detection + proposal cycle
- `/tuner status` — show pending proposals
- `/tuner apply <id> <alt>` — apply a proposal
- `/tuner refuse <id>` — refuse a proposal
- `/tuner revert <id>` — revert an applied proposal
- `/tuner config` — show current configuration
